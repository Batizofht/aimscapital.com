## How the System Works

### New Member Registration Flow
1. Person registers on public website
2. Admin receives notification in dashboard
3. Admin reviews application details
4. Admin clicks "Approve" → Member gets welcome email and can log in
5. OR Admin clicks "Reject" with reason → Member gets email with explanation

### Service Request Flow
1. Member logs in and goes to "My Services"
2. Member clicks "Request" on desired service
3. Admin sees request in Service Requests page
4. Admin reviews and clicks "Approve" or "Reject"
5. Admin can add a message (optional)
6. Member gets email notification + in-app message
7. Member sees updated status in their dashboard

### Appointment Flow
1. Admin creates appointment in dashboard
2. Enters client name, email, date, time, platform
3. Client receives email notification
4. Client sees appointment in their portal
5. Admin confirms appointment → Client gets confirmation
6. Meeting day: Client has meeting link (for virtual)
7. After meeting: Admin marks as "Completed"

### Blog Publishing Flow
1. Admin goes to "Publications" → "New Publication"
2. Writes title, content (supports basic formatting)
3. Uploads cover image
4. Selects category and author
5. Previews the post
6. Toggles "Published" switch
7. Clicks "Save"
8. Post appears on website immediately at aimscapital.rw/blog/
9. Automatically added to Google sitemap for SEO
